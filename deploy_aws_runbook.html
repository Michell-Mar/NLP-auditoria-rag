Runbook de despliegue · AWS

Auditor de Avisos en AWS

Cómo pasar audito_rag_pdf.py de script local a una página donde cualquiera sube un aviso de privacidad, ve el dictamen regla por regla contra la LFPDPPP y deja su retroalimentación.

Alcance: demo / piloto LLM: OpenAI API (gpt-4o) IaC: AWS CDK (Python) Cómputo: serverless (Lambda)
▚

Arquitectura

Una auditoría son 9–11 llamadas secuenciales a gpt-4o (una por regla del DICCIONARIO_LFPDPPP), entre 30 y 90 s en total. API Gateway corta a los 29 s, así que el trabajo no puede ser síncrono: la API solo encola y un worker aparte procesa. El navegador sondea el estado.

Navegador del usuario arrastra el aviso .pdf
CloudFront + S3 · sitio estático (React/Vite) CORS restringido a tu dominio

SQS · cola de trabajos + DLQ

4 · el navegador sondea GET /auditorias/{id} cada 3 s

Decisión · componentes que puedes recortar en el piloto

La Lambda «API» con Function URL ahorra API Gateway (un componente menos), a costa de throttling fino. CloudFront es opcional para enseñar, pero el S3 website endpoint es solo HTTP; para HTTPS con dominio propio sí lo necesitas. Puedes empezar con una sola tabla DynamoDB.

00

Refactor del código para producción

El script hoy carga desde disco, escribe archivos y pregunta por consola. En Lambda nada de eso sirve: el núcleo tiene que recibir bytes, no tocar el disco (salvo /tmp) y devolver un dict. La revisión interactiva (--revisar) se convierte en el formulario web de la Fase 07.

audit_core.py — núcleo reutilizable
import io, os, json
from decimal import Decimal
# ...reutiliza DICCIONARIO_LFPDPPP, construir_chain, genera_resumen,
#    fase_2_vectorizacion, fase_4_y_5_auditoria del archivo actual...

MAX_CHARS_DOC_COMPLETO = int(os.getenv("MAX_CHARS_DOC_COMPLETO", "60000"))

def _cargar_pdf(pdf_bytes: bytes):
    from pypdf import PdfReader
    lector = PdfReader(io.BytesIO(pdf_bytes))          # sin disco
    texto = "\n".join((p.extract_text() or "") for p in lector.pages)
    # ...misma limpieza regex y RecursiveCharacterTextSplitter que fase_1...
    return texto, chunks

def auditar(pdf_bytes: bytes, reglas=None, modelo=None) -> dict:
    reglas = reglas or DICCIONARIO_LFPDPPP
    modelo = modelo or os.getenv("MODELO", "gpt-4o")
    texto, chunks = _cargar_pdf(pdf_bytes)
    doc_completo = len(texto) <= MAX_CHARS_DOC_COMPLETO
    vs = None if doc_completo else fase_2_vectorizacion(chunks)   # ahorra 1 llamada
    chain = construir_chain(modelo)
    resultados, _ = fase_4_y_5_auditoria(chain, vs, texto, reglas)
    salida = {
        "resumen": genera_resumen(resultados),
        "detalle": [{k: v for k, v in r.items() if k != "contexto_usado"}
                    for r in resultados],
    }
    # DynamoDB no acepta float -> Decimal
    return json.loads(json.dumps(salida), parse_float=Decimal)
Cambios mínimos que hay que hacer

1 · Quitar load_dotenv() y toda escritura de chunks_generados.txt / reporte_auditoria.md del núcleo.   2 · fase_4_y_5_auditoria ya acepta vector_store=None cuando doc_completo.   3 · La clave de OpenAI llega por variable de entorno (Fase 03), no por archivo.

02

Almacenamiento y estado

Todo se declara en el stack CDK. Dos tablas y un bucket:

  • S3 Avisos — PDFs subidos. Acceso público bloqueado, cifrado SSE-S3, solo TLS, y regla de ciclo de vida que borra a los 30 días.
  • DynamoDB Auditorias — PK auditId. Guarda estado (PENDIENTE → PROCESANDO → COMPLETADA | ERROR), resumen, detalle, y ttl para autopurga.
  • DynamoDB Retroalimentacion — PK auditId, SK feedbackId. Un item por regla comentada.

04

Backend · Lambda «API»

Una sola función maneja cuatro rutas. No corre la auditoría: reserva el auditId, firma la URL de subida, encola y lee estado.

handlers/api.py
import json, os, uuid, time, boto3

s3  = boto3.client("s3")
sqs = boto3.client("sqs")
AUD = boto3.resource("dynamodb").Table(os.environ["TABLA_AUDITORIAS"])
FB  = boto3.resource("dynamodb").Table(os.environ["TABLA_FEEDBACK"])
BUCKET, COLA = os.environ["BUCKET_AVISOS"], os.environ["COLA_URL"]

def handler(event, _):
    ruta = event["routeKey"]                       # "POST /auditorias"
    pp   = event.get("pathParameters") or {}
    body = json.loads(event.get("body") or "{}")
    ahora = int(time.time())

    if ruta == "POST /auditorias":
        aid = str(uuid.uuid4())
        AUD.put_item(Item={"auditId": aid, "estado": "PENDIENTE",
                           "creadoEn": ahora, "ttl": ahora + 30*86400,
                           "nombreArchivo": body.get("nombreArchivo", "")})
        url = s3.generate_presigned_url("put_object", ExpiresIn=900,
              Params={"Bucket": BUCKET, "Key": f"uploads/{aid}.pdf",
                      "ContentType": "application/pdf"})
        return _r(200, {"auditId": aid, "uploadUrl": url})

    if ruta == "POST /auditorias/{auditId}/procesar":
        sqs.send_message(QueueUrl=COLA, MessageBody=json.dumps({"auditId": pp["auditId"]}))
        AUD.update_item(Key={"auditId": pp["auditId"]},
            UpdateExpression="SET estado = :e", ExpressionAttributeValues={":e": "PROCESANDO"})
        return _r(202, {"estado": "PROCESANDO"})

    if ruta == "GET /auditorias/{auditId}":
        item = AUD.get_item(Key={"auditId": pp["auditId"]}).get("Item")
        return _r(200, item) if item else _r(404, {"error": "no encontrada"})

    if ruta == "POST /auditorias/{auditId}/retroalimentacion":
        for f in body:                              # [{reglaId, deAcuerdo, veredictoUsuario, comentario}]
            FB.put_item(Item={"auditId": pp["auditId"], "feedbackId": str(uuid.uuid4()),
                              "creadoEn": ahora, **f})
        return _r(200, {"registradas": len(body)})

    return _r(400, {"error": "ruta desconocida"})

def _r(code, body):
    return {"statusCode": code, "headers": {"content-type": "application/json"},
            "body": json.dumps(body, default=str)}      # default=str -> Decimal

Las cuatro rutas se conectan al HTTP API en el CDK de la Fase 08 (donde también se define el CORS).

05

Worker asíncrono · SQS + Lambda

La cola SQS desacopla. El worker (misma imagen, otro CMD) toma un mensaje, baja el PDF de S3, llama a audit_core.auditar y escribe el resultado. Si algo falla, deja que SQS reintente; a los 2 intentos cae a la DLQ y salta una alarma.

handlers/worker.py
import json, os, boto3
from handlers import _secreto            # inyecta OPENAI_API_KEY
from audit_core import auditar

s3  = boto3.client("s3")
AUD = boto3.resource("dynamodb").Table(os.environ["TABLA_AUDITORIAS"])

def handler(event, _):
    for record in event["Records"]:                 # batch_size = 1
        aid = json.loads(record["body"])["auditId"]
        try:
            pdf = s3.get_object(Bucket=os.environ["BUCKET_AVISOS"],
                                Key=f"uploads/{aid}.pdf")["Body"].read()
            res = auditar(pdf)                       # {"resumen": …, "detalle": …}
            AUD.update_item(Key={"auditId": aid},
                UpdateExpression="SET estado=:e, resumen=:r, detalle=:d",
                ExpressionAttributeValues={":e": "COMPLETADA",
                    ":r": res["resumen"], ":d": res["detalle"]})
        except Exception as e:
            AUD.update_item(Key={"auditId": aid},
                UpdateExpression="SET estado=:e, #err=:m",
                ExpressionAttributeNames={"#err": "error"},
                ExpressionAttributeValues={":e": "ERROR", ":m": str(e)})
            raise                                   # -> reintento SQS -> DLQ
infra/app.py — el stack completo
from aws_cdk import (App, Stack, Duration, RemovalPolicy, CfnOutput,
    aws_s3 as s3, aws_dynamodb as ddb, aws_sqs as sqs, aws_lambda as lb,
    aws_apigatewayv2 as gw, aws_apigatewayv2_integrations as integ,
    aws_secretsmanager as sm, aws_lambda_event_sources as src)
from constructs import Construct

DOMINIO = "https://auditor.tu-dominio.mx"

class AuditorStack(Stack):
    def __init__(self, scope: Construct, cid: str, **kw):
        super().__init__(scope, cid, **kw)

        avisos = s3.Bucket(self, "Avisos",
            block_public_access=s3.BlockPublicAccess.BLOCK_ALL,
            encryption=s3.BucketEncryption.S3_MANAGED, enforce_ssl=True,
            lifecycle_rules=[s3.LifecycleRule(expiration=Duration.days(30))],
            cors=[s3.CorsRule(allowed_methods=[s3.HttpMethods.PUT],
                  allowed_origins=[DOMINIO], allowed_headers=["*"])])

        auditorias = ddb.TableV2(self, "Auditorias",
            partition_key=ddb.Attribute(name="auditId", type=ddb.AttributeType.STRING),
            billing=ddb.Billing.on_demand(), time_to_live_attribute="ttl",
            removal_policy=RemovalPolicy.DESTROY)
        feedback = ddb.TableV2(self, "Retroalimentacion",
            partition_key=ddb.Attribute(name="auditId", type=ddb.AttributeType.STRING),
            sort_key=ddb.Attribute(name="feedbackId", type=ddb.AttributeType.STRING),
            billing=ddb.Billing.on_demand())

        dlq  = sqs.Queue(self, "TrabajosDLQ")
        cola = sqs.Queue(self, "Trabajos", visibility_timeout=Duration.seconds(960),
            dead_letter_queue=sqs.DeadLetterQueue(max_receive_count=2, queue=dlq))

        secreto = sm.Secret.from_secret_name_v2(self, "OpenAI", "auditor/openai")
        entorno = {"TABLA_AUDITORIAS": auditorias.table_name,
                   "TABLA_FEEDBACK":   feedback.table_name,
                   "BUCKET_AVISOS":    avisos.bucket_name,
                   "COLA_URL":         cola.queue_url,
                   "OPENAI_SECRET_ARN": secreto.secret_arn}

        api_fn = lb.DockerImageFunction(self, "ApiFn",
            code=lb.DockerImageCode.from_image_asset("..", cmd=["handlers.api.handler"]),
            architecture=lb.Architecture.ARM_64, memory_size=1024,
            timeout=Duration.seconds(29), environment=entorno)

        worker_fn = lb.DockerImageFunction(self, "WorkerFn",
            code=lb.DockerImageCode.from_image_asset("..", cmd=["handlers.worker.handler"]),
            architecture=lb.Architecture.ARM_64, memory_size=2048,
            timeout=Duration.seconds(900), environment=entorno)
        worker_fn.add_event_source(src.SqsEventSource(cola, batch_size=1))

        for fn in (api_fn, worker_fn):
            auditorias.grant_read_write_data(fn); secreto.grant_read(fn)
        feedback.grant_read_write_data(api_fn)
        avisos.grant_put(api_fn); avisos.grant_read(worker_fn)
        cola.grant_send_messages(api_fn)

        http = gw.HttpApi(self, "Http", cors_preflight=gw.CorsPreflightOptions(
            allow_origins=[DOMINIO], allow_headers=["content-type"],
            allow_methods=[gw.CorsHttpMethod.GET, gw.CorsHttpMethod.POST]))
        i = integ.HttpLambdaIntegration("ApiInteg", api_fn)
        http.add_routes(path="/auditorias", methods=[gw.HttpMethod.POST], integration=i)
        http.add_routes(path="/auditorias/{auditId}", methods=[gw.HttpMethod.GET], integration=i)
        http.add_routes(path="/auditorias/{auditId}/procesar",
                        methods=[gw.HttpMethod.POST], integration=i)
        http.add_routes(path="/auditorias/{auditId}/retroalimentacion",
                        methods=[gw.HttpMethod.POST], integration=i)

        CfnOutput(self, "ApiUrl", value=http.api_endpoint)

app = App(); AuditorStack(app, "Auditor", env={"region": "us-east-1"}); app.synth()

06

Frontend

App React con Vite. Tres pantallas en una: zona de arrastre, estado con sondeo, y la tabla de resultados con el formulario de retroalimentación. El PDF sube directo a S3 con la URL prefirmada — nunca pasa por la Lambda (que tiene un límite de 6 MB de payload).

web/src/api.js
const API = import.meta.env.VITE_API_URL;

export async function auditar(archivo, onEstado) {
  const { auditId, uploadUrl } = await fetch(`${API}/auditorias`, {
    method: "POST", headers: { "content-type": "application/json" },
    body: JSON.stringify({ nombreArchivo: archivo.name }),
  }).then(r => r.json());

  await fetch(uploadUrl, { method: "PUT",
    headers: { "content-type": "application/pdf" }, body: archivo });

  await fetch(`${API}/auditorias/${auditId}/procesar`, { method: "POST" });

  while (true) {
    await new Promise(r => setTimeout(r, 3000));
    const a = await fetch(`${API}/auditorias/${auditId}`).then(r => r.json());
    onEstado?.(a.estado);
    if (a.estado === "COMPLETADA") return a;
    if (a.estado === "ERROR") throw new Error(a.error);
  }
}

export const enviarFeedback = (auditId, items) =>
  fetch(`${API}/auditorias/${auditId}/retroalimentacion`, {
    method: "POST", headers: { "content-type": "application/json" },
    body: JSON.stringify(items),
  });

Cada desacuerdo es una fila de un futuro set de evaluación: mide la exactitud del modelo por regla, detecta qué reglas del DICCIONARIO_LFPDPPP están mal redactadas, y alimenta ajustes al prompt del auditor. Expórtalo con un scan a CSV cuando tengas volumen.

08

Dominio, HTTPS y CORS

  • Zona alojada en Route 53 (o delega los NS desde tu registrador).
  • Certificado ACM en us-east-1, validación DNS, para auditor.tu-dominio.mx.
  • Distribución CloudFront con OAC apuntando al bucket del sitio (el bucket sigue privado), y registro A alias hacia ella.
  • El CORS del HTTP API y del bucket de avisos se cierra exactamente a ese origen (variable DOMINIO en el CDK). Nada de *.
  • Límites de throttling en el stage del HTTP API (p. ej. 20 rps, ráfaga 40) para que una demo pública no dispare la factura de OpenAI.

Observabilidad y límites

  • CloudWatch Logs con retención de 14 días en ambas funciones (evita costo y datos viejos).
  • Alarmas: mensajes visibles en la DLQ > 0; Errors del worker; Duration p95 acercándose a 900 s.
  • Métrica de negocio: publica auditorías_completadas y llamadas_openai como métricas embebidas (EMF) para ver consumo real.
  • Panel: un dashboard con invocaciones, errores, profundidad de cola y costo estimado de OpenAI del día.
  • Lambda Powertools (Python) da logging estructurado, tracing y métricas con muy poco código.
▚

Seguridad y cumplimiento

La herramienta audita cumplimiento de la LFPDPPP: sería incoherente que ella misma no cumpliera. Antes de exponerla:

  • S3 y DynamoDB cifrados en reposo; todo el tráfico por TLS (enforce_ssl, política de bucket que niega aws:SecureTransport = false).
  • IAM de mínimo privilegio: cada grant_* apunta al ARN concreto de la tabla / bucket / cola. Cero Resource: "*".
  • Ciclo de vida de S3 borra los PDFs a los 30 días; ttl de DynamoDB purga las auditorías. Endpoint de borrado inmediato a petición (derecho de cancelación).
  • Los logs registran auditId y estado, nunca el texto del PDF ni la respuesta cruda de OpenAI.
  • CORS y throttling cerrados a tu dominio. WAF con regla de rate-limit si la demo es pública.
  • La app tiene su propio aviso de privacidad y advierte que el documento se procesa con un tercero en EE. UU. (OpenAI) — una transferencia internacional que el usuario acepta.
  • Un aviso de privacidad es una plantilla pública sin datos personales; aun así, valida el Content-Type, limita el tamaño (p. ej. 10 MB) y rechaza lo que no sea PDF.
  • Contrato con OpenAI vía API: los datos no se usan para entrenar por defecto. Documenta esto en tu registro de tratamientos.
Alternativa que elimina la transferencia

Si el piloto crece, mover el dictamen a Claude en Amazon Bedrock mantiene los avisos dentro de tu cuenta de AWS y la misma región — y quita de la ecuación el secreto de OpenAI, el componente externo y la cláusula de transferencia. La capa construir_chain() ya aísla el proveedor.
